Entry for the [make.fun](https://make.fun/bounty/u-ricoxyz-loading-screen-gold-a-tip-in-200-characters-2b1df270) bounty **Loading Screen Gold: A Tip in 200 Characters**.

`main.py` (Python 3.13, stdlib only) writes one loading-screen tip to
`$MAKEFUN_OUTPUT_DIR/entry.txt`:

> Tip: while this loads, the agent is reading your code twice — once to understand it, once to forgive it.

104 characters, one line, UTF-8. The program enforces the 1–200 character
gate, single-line and non-whitespace checks, and verifies the written file
with a byte-exact read-back before exiting.
